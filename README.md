# File validation busboy

This project does take care of uploading and validating the file got from user in a way that it doesn't break the app. It rejects the file early without wasting server reources. It saves the file on a hard drive cause I think it's cheaper for small companies to use a server with hard drive than a subscription from AWS but I might be wrong.
