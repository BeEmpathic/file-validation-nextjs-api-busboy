## To run project:

### 1. Install:

- node.js / node package manager

### 2. Run npm run dev

after cloning inside the unpacked folder with the porject run:

This installs the pacages:
```bash
npm i
```

then start the dev server:

```bash
npm run dev
```
you can do production server, but it's app to you.
